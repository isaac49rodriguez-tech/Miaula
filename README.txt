# Mi Aula - Página para compartir archivos

## Cómo agregar tus archivos

1. Pon el PDF, Word, PowerPoint, imagen, etc. dentro de la carpeta `archivos`.
2. Abre `script.js`.
3. Copia uno de los objetos de ejemplo dentro de `const files`.
4. Cambia:
   - `name`: nombre que aparecerá en la página.
   - `description`: descripción.
   - `category`: Contabilidad, Español, Sociales u Otros.
   - `type`: PDF, DOCX, PPTX, JPG, etc.
   - `icon`: emoji que quieras mostrar.
   - `path`: nombre exacto del archivo dentro de `archivos`.
5. Guarda todo.
6. Abre `index.html` para probar la página.

## Publicarla gratis

Una opción sencilla es GitHub Pages. Crea un repositorio, sube `index.html`, `styles.css`, `script.js` y la carpeta `archivos`, y activa Pages desde la configuración del repositorio.

IMPORTANTE:
- No subas contraseñas, documentos privados ni información personal.
- Los archivos publicados en una página pública podrán ser descargados por cualquiera que tenga acceso a ella.
